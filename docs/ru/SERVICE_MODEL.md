Бесплатные hosted-виджеты дают полный результат на сайте владельца, логотип NutriFit, источники и добровольные ссылки. Каталог использует существующие локальные формулы и опросники; его публичный PDF — снимок показанных значений. Калькулятор блюда использует серверный каталог, расчёт и свежий PDF; CSV локальный. MIT распространяется на код, а не на товарные знаки, квоты сервиса или права на клинические инструменты. Для бесплатного результата аккаунт не нужен.

Платный hosted white-label использует подтверждённый точный HTTPS-домен и integrationId с серверным брендом клиента. В каталоге без бренда кнопка PDF NutriFit отсутствует; PDF/CSV блюда используют бренд клиента. Native React — именно калькулятор блюда: нужен тариф с native-доступом и серверный ключ. Личный Premium не даёт права на виджеты.

Настроенные тарифы подключаются в кабинете. Stripe выдаёт доступ после подтверждённых платёжных событий; отмена продления сохраняет оплаченный период. Покупка из кошелька использует доступный USD-баланс на один календарный месяц; поддерживаемые криптопополнения увеличивают этот баланс. Банковские переводы требуют фиксации подтверждённого платежа поддержкой. Цены, число сайтов и месячные операции задаёт NutriFit. Автоматическое продление кошельком, бесплатный период, grace, перерасход и SLA не обещаются. Домен подтверждается DNS TXT. Ротация и отключение ключа отзывают прежние сессии; квота обновляется каждый календарный месяц UTC. Формульные расчёты не расходуют квоту API питания.

Iframe защищает свой документ от CSS сайта, но не предотвращает обрезку или перекрытие. Бренд и переходы — измеримая польза, без гарантии SEO или выручки. События передают только жизненный цикл, без ответов посетителя или значений нутриентов.
