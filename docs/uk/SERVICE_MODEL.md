Безкоштовні віджети дають повний результат, логотип, джерела й добровільні посилання без акаунта. Каталог використовує локальні формули й опитувальники; його PDF — знімок показаних значень. Страва використовує серверний каталог, розрахунок, новий PDF і локальний CSV. MIT охоплює код, а не торгові марки, квоти або права на клінічні інструменти.

White-label потребує підтвердженого точного HTTPS-домену й integrationId; бренд визначає сервер. У каталозі white-label кнопки PDF NutriFit немає; PDF/CSV страви мають бренд клієнта. Native React — лише страва з тарифом native і серверним ключем. Особистий Premium не включає віджети.

Stripe надає доступ після підтверджених подій; скасування продовження зберігає оплачений період. USD-баланс купує календарний місяць, підтримувані криптопоповнення фінансують баланс. Переказ підтверджує підтримка. Ціни, сайти й місячні операції задає NutriFit; пробний період, grace, перевитрати, SLA й автоматичне продовження гаманцем не обіцяються. DNS TXT підтверджує домен; ротація відкликає сесії, квоти оновлюються щомісяця UTC. Локальні формули не витрачають квоту харчування. Iframe не запобігає обрізанню; бренд не гарантує SEO. Події не містять відповідей або нутрієнтів.
