[← O‘zbekcha](README.md)

Bepul vidjetlar akkauntsiz to‘liq natija, logo, manbalar va ixtiyoriy havolalarni beradi. Katalog mahalliy formulalar va so‘rovnomalardan foydalanadi; PDF ko‘rsatilgan qiymatlarning nusxasi. Taom server katalogi, hisoblash, yangi PDF va mahalliy CSV dan foydalanadi. MIT kodga tegishli, savdo belgilari, kvota yoki klinik vositalar huquqiga emas.

White-label aniq tasdiqlangan HTTPS domen va integrationId talab qiladi; brendni server belgilaydi. Katalog white-label da NutriFit PDF tugmasi yo‘q; taom PDF/CSV mijoz brendini ishlatadi. Native React faqat taom, native tarif va server kaliti talab qiladi. Shaxsiy Premium vidjetlarni o‘z ichiga olmaydi.

Stripe faqat tasdiqlangan hodisadan so‘ng huquq beradi; yangilashni bekor qilish to‘langan muddatni saqlaydi. USD balans bir kalendar oy sotib oladi; qo‘llanadigan kripto to‘ldirish balansni moliyalashtiradi. Bank to‘lovini yordam xizmati tasdiqlaydi. Narx, sayt va oylik operatsiyalarni NutriFit belgilaydi. Sinov, grace, ortiqcha sarf, SLA va hamyonni avtomatik yangilash va’da qilinmaydi. DNS TXT domenni tekshiradi; kalit almashtirilsa sessiya bekor bo‘ladi, kvota UTC bo‘yicha har oy yangilanadi. Formulalar oziq API kvotasini sarflamaydi. Iframe kesib yashirishni to‘xtatmaydi; brend SEO kafolati emas. Hodisalar javoblar yoki oziq qiymatlarini yubormaydi.
