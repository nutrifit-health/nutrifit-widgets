Тегін виджеттер аккаунтсыз толық нәтиже, логотип, дереккөздер және ерікті сілтемелер береді. Каталог жергілікті формулалар мен сауалнамаларды қолданады; PDF көрсетілген мәндердің көшірмесі. Тағам серверлік каталог пен есептеуді, жаңа PDF және жергілікті CSV қолданады. MIT кодқа ғана қатысты, сауда белгілеріне, квотаға немесе клиникалық құрал құқықтарына емес.

White-label үшін дәл HTTPS домені мен integrationId расталуы керек; брендті сервер анықтайды. Каталог white-label ішінде NutriFit PDF батырмасы жоқ; тағам PDF/CSV клиент брендін қолданады. Native React тек тағамды қолдайды, native тарифі мен серверлік кілт қажет. Жеке Premium виджеттерді қамтымайды.

Stripe тек расталған оқиғалардан кейін құқық береді; жаңартуды тоқтату төленген мерзімді сақтайды. USD балансы бір күнтізбелік ай сатып алады; қолдау көрсетілетін криптотолтырулар сол балансты толықтырады. Банктік төлемді қолдау қызметі растайды. Баға, сайт және айлық операцияларды NutriFit баптайды. Сынақ мерзімі, grace, артық пайдалану, SLA және әмиянды автоматты жаңарту уәде етілмейді. DNS TXT доменді растайды; кілт ауысуы сессияны тоқтатады, квота ай сайын UTC бойынша жаңарады. Формулалар тағам API квотасын жұмсамайды. Iframe қиып жасырудан қорғамайды; бренд SEO-ға кепіл емес. Оқиғалар жауаптар мен нутриент мәндерін жібермейді.
