# Changelog

## 1.0.0

- 49 branded widgets: the dish nutrition calculator and all 48 public catalog calculators.
- Six languages: English, Russian, Spanish, Ukrainian, Kazakh and Uzbek.
- React iframe components, JavaScript loader, mount API and plain iframe integration.
- Optional native React dish calculator with server-issued sessions.
- Official light/dark logos and automatic system theme; server-managed white-label access.
- Six language folders with individual calculator pages, embedding examples, methods, sources and limitations.
- Branded reports, localized CSV and anonymous catalog PDF transport.
- GitHub and npm release metadata and documented publishing procedure.
